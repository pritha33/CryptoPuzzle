# CryptoPuzzle
A browser-based educational game that challenges players to decrypt messages encoded with classic ciphers. Built with vanilla HTML, CSS, and JavaScript.

🎮 About the Project
CryptoPuzzle Game is an interactive web application designed to make learning about classical cryptography fun and engaging. Players are presented with encrypted text along with hints about the encryption algorithm and key used. The goal is to decrypt the cipher and guess the original plaintext to earn points.

✨ Features
Three Classic Ciphers:

Vigenère Cipher – Polyalphabetic substitution using a keyword
Rail Fence Cipher – Transposition cipher that writes text in a zigzag pattern
Playfair Cipher – (simplified demo version) a digraph substitution cipher

Randomized Puzzles: Each puzzle randomly selects a plaintext, key, and cipher algorithm, so no two games are the same.
Scoring System:

✅ Correct answer: +10 points
❌ Wrong answer: −5 points

Simple UI: Clean, centered layout with buttons to play, view score, or reset the game.
